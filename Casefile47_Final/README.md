# CASEFILE: 47 — The Last Night at MIT University

Java Swing detective game. No external libraries.

## Run in IntelliJ
Open the project, mark `src` as Sources Root if needed, then run `src/detective/Main.java`.

## Command line
javac -d out src/detective/Main.java
java -cp out detective.Main

Features: 5 suspects, 9 locations, witness/evidence-style investigation, interviews, interrogation follow-ups, deduction board, final accusation and multiple endings.
